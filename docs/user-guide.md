# EveryDB 使い方

## データソースを追加する

1. サイドバー右上の「追加」を押します。
2. 種別を選び、表示名と接続情報を入力します。
3. トークン、クライアントシークレット、DBパスワードは、必要に応じて「保存済みから選択」で既存の認証情報を選びます。
4. 「保存してリロード」を実行します。取得に成功すると件数と最終更新時刻がサイドバーへ表示されます。

種別ごとの必要項目は [データソース一覧と接続手順](data-sources.md) を参照してください。

## 検索する

- 上部の検索欄に語句を入力します。半角空白で区切った語句はすべて含む結果を検索します。
- サイドバーのチェックで検索対象を限定できます。
- 列見出しを押すと昇順、降順、未ソートの順に切り替わります。
- 結果セルを右クリックすると、コピー、元の参照先を開く、対象ソースの非表示、エクスポートなどを利用できます。

## 更新・編集・削除する

- 各ソースの更新ボタン、または接続先グループの更新ボタンで再読込します。
- 右クリックまたは管理モードから名前・設定・列の表示設定を編集できます。
- 削除前には確認ダイアログが表示されます。削除するとキャッシュ済みレコードも削除されます。

## 認証情報を管理する

「設定」→「保存済みトークンの管理」では、Notion、Airtable、Microsoft 365、Box、PostgreSQL、MySQL の認証情報を名前付きで保存・再利用できます。

使用中の認証情報は削除できません。置換した値は、その認証情報を参照するソースで次回取得時から使われます。秘密値を表示する際は Windows Hello の確認が求められることがあります。

## エクスポートする

検索結果は TSV、CSV、JSON として保存できます。文字コードは UTF-8（BOMあり／なし）または Shift_JIS を選べます。保存先はWindowsのファイル選択ダイアログで指定します。

## 常駐・ショートカット

EveryDB は閉じても通知領域へ格納されます。既定のグローバルショートカットは `Alt+Ctrl+D` です。設定画面から自動起動、テーマ、ズーム、ショートカットを変更できます。
