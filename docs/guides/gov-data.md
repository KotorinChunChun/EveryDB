# 政府公開データ（郵便番号・法人番号）の接続手順

対象の EveryDB 種別: **郵便番号データベース(日本郵便) / 法人番号 全件データ(国税庁)**

## 概要

認証不要で公開されている政府系のデータを、アプリが自動でダウンロードして取り込みます。
郵便番号は全国一括、法人番号は都道府県ごと（または全国一括）に取得できます。

## 事前に必要なもの

- 特にありません（アカウント・API キーは不要）。インターネット接続だけが必要です。

## 手順

1. データソース一覧の **＋追加** を押します。
2. 種別で「郵便番号データベース(日本郵便)」または「法人番号 全件データ(国税庁)」を選びます。
3. 法人番号の場合は**都道府県**を選びます（全国一括を取り込みたい場合は「全国」を選択。
   ただし全国分は非常に件数が多くダウンロードに時間がかかります）。
4. **取得元**は既定の「自動ダウンロード」のままで問題ありません。
5. **保存してリロード**を押すと、取得〜取り込みが始まります（法人番号・郵便番号とも
   全国データの場合は数分かかることがあります）。

## EveryDB 側の入力項目

| 項目 | 入力する値 | 備考 |
| :--- | :--- | :--- |
| 都道府県（法人番号のみ） | 対象の都道府県、または「全国」 | - |
| 取得元 | 自動ダウンロード（既定） / ファイル指定 | 通常は自動ダウンロードのままでよい |
| ファイル指定時のパス | 手動でダウンロードした zip または csv のパス | 取得元が「ファイル指定」のときだけ使用 |

## 自動ダウンロードが失敗するとき（サイト構造の変更時の代替手段）

法人番号は国税庁サイトのページ構造を読み取ってダウンロード ID を特定する方式のため、
**サイトが改修されると自動ダウンロードが失敗することがあります**。その場合は次の手順で
手動ダウンロードしたファイルを指定してください。

1. [法人番号 全件データのダウンロードページ](https://www.houjin-bangou.nta.go.jp/download/zenken/index.html)
   を開き、「CSV形式・Unicode」から対象の都道府県の zip をダウンロードします。
2. EveryDB の追加/接続設定画面で**取得元**を「ファイル指定」に切り替え、
   ダウンロードした zip（または展開後の csv）のパスを指定します。

郵便番号も同様に、[郵便番号データダウンロード](https://www.post.japanpost.jp/service/search/zipcode/download/utf/zip/utf_ken_all.zip)
から zip を手動取得し、「ファイル指定」で指定できます。

## よくあるエラーと対処

| 症状 | 原因 | 対処 |
| :--- | :--- | :--- |
| 「都道府県のダウンロードIDが見つかりません」 | 国税庁サイトのページ構造が変わった | 上記の手動ダウンロード手順でファイル指定に切り替える |
| 「CSRFトークンが見つかりません」 | 同上 | 同上 |
| ダウンロードに時間がかかる/失敗する | 「全国」は数百MBあり回線・タイムアウトの影響を受けやすい | 都道府県単位で分けて取り込む |
| CSV の文字コードが UTF-8 ではありません | ファイル指定で Shift_JIS 版を指定した | 「CSV形式・Unicode」（UTF-8）版を指定する |
