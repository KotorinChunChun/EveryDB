# Google スプレッドシートの接続手順

対象の EveryDB 種別: **Google スプレッドシート**

## 概要

Google Cloud の**サービスアカウント**（人ではなくプログラム用のアカウント）を作り、その JSON 鍵で
スプレッドシートを読み取ります。対象のシートを**サービスアカウントのメールアドレスに共有**する
必要があります。

## 事前に必要なもの

- Google アカウントと、Google Cloud プロジェクトを作成できる権限
- 取り込みたいスプレッドシート

## 手順

1. 入力欄の横の **🔑 取得…** を押して [Google Cloud の認証情報](https://console.cloud.google.com/apis/credentials) を開きます。
2. 画面上部でプロジェクトを選ぶ（無ければ新規作成）。
3. **API とサービス** → **ライブラリ** で **Google Sheets API** を検索し、**有効にする**を押します。
4. **認証情報** → **認証情報を作成** → **サービス アカウント** を選び、名前を付けて作成します。
5. 作成したサービスアカウントを開き、**キー** タブ → **鍵を追加** → **新しい鍵を作成** →
   **JSON** を選ぶと鍵ファイルがダウンロードされます。PC 上の安全な場所に保存してください。
6. 同じ画面に出ている**サービスアカウントのメールアドレス**
   （`...@....iam.gserviceaccount.com`）をコピーします。
7. 取り込みたいスプレッドシートを開き、**共有** から手順 6 のメールアドレスを
   **閲覧者**として追加します。**この共有をしないと読み取れません。**
8. EveryDB の「サービスアカウント鍵(JSON)のパス」に手順 5 のファイルを指定し、
   スプレッドシート ID を入力して保存します。

## EveryDB 側の入力項目

| 項目 | 入力する値 | 備考 |
| :--- | :--- | :--- |
| サービスアカウント鍵(JSON)のパス | 手順 5 で保存した JSON ファイル | **参照…** から選べます |
| スプレッドシートID | URL の `/d/` と `/edit` の間の文字列 | |
| 範囲(任意) | `Sheet1!A1:D50` 等 | 空欄なら先頭シート全域 |
| 先頭行はヘッダー | 通常は ON | OFF だと列名が連番になります |

使用する権限（スコープ）は読み取り専用の
`https://www.googleapis.com/auth/spreadsheets.readonly` です。

## よくあるエラーと対処

| 症状 | 原因 | 対処 |
| :--- | :--- | :--- |
| `403 PERMISSION_DENIED` | シートを共有していない | 手順 7 を実施 |
| `403 Google Sheets API has not been used` | API が無効 | 手順 3 を実施 |
| `秘密鍵の読み込みに失敗` | JSON 鍵の破損・別形式（P12 等） | JSON 形式の鍵を作り直す |
| 取得は成功するが 0 件 | 範囲指定が空のセルを指している | 「範囲」を空欄にするか正しい範囲へ |
