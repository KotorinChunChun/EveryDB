# WEBサイトの情報をデータソース化する手順

対象の EveryDB 種別: **WEBサイト(HTML表 / CSSセレクタ / JSON API)**

## 概要

指定した URL に GET でアクセスし、その内容をテーブルとして取り込みます。3 つの取り込み方式
（モード）があり、対象サイトの作り方に応じて使い分けます。

| モード | 向いているサイト |
| :--- | :--- |
| HTML表(table)を自動取込 | ページ内に `<table>` があるだけの、いわゆる静的なサイト |
| CSSセレクタで行/列を指定 | table ではなく `<div>`/`<article>` の繰り返しで一覧を作っているサイト |
| JSON APIを取込 | ページ自体は JavaScript で描画され、裏側の API が JSON を返すサイト |

> **重要**: 近年の多くのサイト（検索結果ページなど）は JavaScript でページを描画するため、
> ページの HTML そのものには結果が含まれないことがあります。その場合は「HTML表」
> 「CSSセレクタ」のどちらを選んでも 0 件になります。ブラウザの開発者ツール（F12）の
> **Network タブ**でページ読み込み時にどの URL が JSON を返しているか確認し、
> その URL を「JSON APIを取込」で指定してください。

## 事前に必要なもの

- 対象ページの URL（検索結果ページ等はクエリパラメータを含めた URL をそのまま指定）
- CSSセレクタ/JSON APIモードの場合は、対象サイトの HTML 構造または API のレスポンス構造の把握
  （ブラウザの開発者ツールで確認）

## 手順（共通）

1. データソース一覧の **＋追加** を押します。
2. 種別で「WEBサイト」を選びます。
3. **URL** に対象ページ（または API）の URL を入力します。
4. **取り込み方式**を選び、下記のモード別入力項目を埋めます。
5. **保存してリロード**を押すと取り込みが始まります。

## モード別の入力項目

### HTML表(table)を自動取込

| 項目 | 入力する値 |
| :--- | :--- |
| 何番目の\<table\>か | ページ内に複数 table がある場合、0 始まりで指定（既定 0） |
| 先頭行を見出しにする | 先頭行を列見出しとして扱うか（既定 ON） |

### CSSセレクタで行/列を指定

| 項目 | 入力する値 |
| :--- | :--- |
| 行のCSSセレクタ | 1 件分の要素を指すセレクタ（例: `article.post`） |
| 列定義 | 1 行に 1 列、`表示名=セレクタ` の形式。セレクタは**行要素を起点にした相対指定**。属性値を取りたい場合は `表示名=セレクタ@属性名`（例: `URL=h2 a@href`） |

### JSON APIを取込

| 項目 | 入力する値 |
| :--- | :--- |
| 配列を取り出すJSONパス | レスポンス JSON のうち配列になっている部分へのドット区切りパス（例: `articles`）。レスポンス自体が配列なら空欄でよい |
| 列定義 | 1 行に 1 列、`表示名=ドットパス`（例: `タイトル=title`、`投稿者=user.name`）。空欄のままなら各要素のトップレベルのキーをそのまま列にする |

## 実例: zenn.dev の検索結果を取り込む

`https://zenn.dev/search?q=vba` のページ自体は JavaScript 描画で HTML に結果が含まれないため、
開発者ツールの Network タブで確認すると `https://zenn.dev/api/search?q=vba&source=articles`
という JSON API が結果を返していることが分かります。この URL を JSON API モードで、
配列を取り出すJSONパスに `articles` を指定すると取り込めます。

## よくあるエラーと対処

| 症状 | 原因 | 対処 |
| :--- | :--- | :--- |
| 「テーブルからデータ行を取得できませんでした」「row_selector に一致する要素が見つかりませんでした」 | ページが JavaScript で描画されており HTML に結果が無い | 開発者ツールの Network タブで実際のデータ取得先 API を探し、JSON APIモードに切り替える |
| 「json_root に一致するデータが見つかりません」 | 指定したドットパスが実際のレスポンス構造と違う | 開発者ツールでレスポンスの JSON 構造を確認し直す |
| 「セレクタが不正です」 | CSS セレクタの書式誤り | ブラウザの開発者ツールで対象要素を右クリック→「コピー」→「セレクタをコピー」で確認 |
