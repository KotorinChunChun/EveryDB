# Google カレンダー / iCal (.ics) の接続手順

対象の EveryDB 種別: **Google カレンダー / iCal (.ics)**

## 概要

公開されている iCal 形式（`.ics`）の URL を取得して予定を取り込みます。API キーは不要ですが、
**URL を知っていれば誰でも中身を見られる**点に注意してください。

## 事前に必要なもの

- 取り込みたいカレンダーと、その iCal URL

## 手順（Google カレンダーの場合）

1. ブラウザで [Google カレンダー](https://calendar.google.com/) を開きます。
2. 左の「マイカレンダー」で対象カレンダーの **︙** →「**設定と共有**」を開きます。
3. **カレンダーの統合** の項目まで下がります。
   - 社内など**限定公開のまま**使う場合: **カレンダーの非公開 URL（iCal 形式）** をコピーします。
     この URL は秘密情報として扱ってください（漏れると誰でも閲覧できます）。
   - **一般公開**して構わない場合: 先に「**予定へのアクセス権**」で一般公開を有効にし、
     **公開 URL（iCal 形式）** をコピーします。
4. EveryDB の「公開 iCal URL」に貼り付けて保存します。

## 手順（Outlook / その他）

- Outlook on the web: **設定** → **カレンダー** → **共有カレンダー** →
  「カレンダーの公開」で ICS リンクを発行します。
- その他のサービスでも「iCal」「ICS」「カレンダーの購読 URL」といった名称で提供されています。
  `webcal://` で始まる URL は `https://` に置き換えて入力してください。

## EveryDB 側の入力項目

| 項目 | 入力する値 | 備考 |
| :--- | :--- | :--- |
| 公開 iCal URL | `https://.../basic.ics` | `webcal://` は `https://` に直す |

## よくあるエラーと対処

| 症状 | 原因 | 対処 |
| :--- | :--- | :--- |
| `404` / `403` | 非公開のまま公開 URL を使っている | 手順 3 で正しい URL を選ぶ |
| 0 件 | カレンダーに予定が無い / 期間外 | カレンダー側を確認 |
| 文字化け | 提供元が非 UTF-8 で配信 | 提供元の設定を確認 |
