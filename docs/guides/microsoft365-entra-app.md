# 組織のMicrosoftアプリケーション認証の接続手順

対象の EveryDB 種別: **Entra ID ユーザー / グループ / デバイス一覧、Intune デバイス一覧、
Microsoft 365 ライセンス一覧、Teams チーム一覧、SharePoint リスト / ドキュメントライブラリ、
Outlook 予定表、OneDrive（組織）、Teams タスク & Planner**

> 本ファイルは **アプリケーション認証（クライアントシークレット / アプリケーション認証）** の個別手順です。
> 個人 Microsoft アカウントではなく、会社・学校の Microsoft 365 組織を対象にします。
> 方式の比較と選び方は [Microsoft Graph 接続方法の選択](microsoft365.md)、
> ユーザー委任は [委任 OAuth の接続手順](microsoft365-entra-user.md) を参照してください。

## 概要

Microsoft Entra ID（旧 Azure AD）にアプリを登録し、**クライアントシークレット**による
アプリケーション認証（ユーザーの対話ログインを伴わない）で Microsoft Graph からデータを取得します。
必要な API アクセス許可には**テナント管理者の同意**が必要です。

## 事前に必要なもの

- Microsoft 365 テナントの**全体管理者**（または、アプリ登録と管理者の同意ができる権限）
- 取り込みたいデータに対応する Graph アクセス許可（下表）

## 手順

1. [Entra 管理センターのアプリ登録](https://entra.microsoft.com/#view/Microsoft_AAD_RegisteredApps/ApplicationsListBlade) を開きます。
2. **新規登録** を押し、名前（例: `EveryDB`）を入力して登録します。
   サポートされるアカウントの種類は「この組織ディレクトリのみ」で構いません。
3. 登録直後の**概要**画面に出る次の 2 つをコピーします。
   - **アプリケーション (クライアント) ID** → EveryDB の「クライアントID」
   - **ディレクトリ (テナント) ID** → EveryDB の「テナントID」
4. 左メニュー **証明書とシークレット** → **新しいクライアント シークレット** を作成します。
   作成直後に表示される **値**（Value）をコピーします（**ID ではありません**。
   画面を離れると二度と表示されません）。→ EveryDB の「クライアントシークレット(値)」
5. 左メニュー **API のアクセス許可** → **アクセス許可の追加** → **Microsoft Graph** →
   **アプリケーションの許可** から、下表のうち必要なものを追加します。
6. 同じ画面で **「（テナント名）に管理者の同意を与えます」** を押します。
   状態がすべて「付与されました」になれば完了です。
7. 続けて、次の「EveryDB での安全な登録方法」に従って資格情報を保存し、接続先を追加します。

## EveryDB での安全な登録方法

テナントID・クライアントID・クライアントシークレットは、接続設定ごとに直接保存しません。

1. **設定** → **🔑 保存済みトークンの管理…** を開き、種別 **Microsoft Entra ID（組織）** のプロファイルを新規作成します。
2. 任意のラベルと、手順 3・4 で取得したテナントID、クライアントID、クライアントシークレットを入力して保存します。
3. Graph 接続の追加・編集画面で認証情報欄の **選択…** を押し、保存したプロファイルを選びます。

クライアントシークレットには有効期限があります。期限が切れる前に新しい値へ更新し、
値そのものを手順書、スクリーンショット、ログへ記録しないでください。
認証方式情報が無い旧バージョンの Graph プロファイルは、後方互換のため
アプリケーション認証として扱われます。既存接続の移行操作は不要です。

## 必要な Graph アクセス許可

ここでは必ず **アプリケーションの許可** を追加してください。
同名の **委任されたアクセス許可** を追加しても、この認証方式では利用できません。

| EveryDB の種別                           | 必要なアプリケーションの許可                                       |
| :--------------------------------------- | :----------------------------------------------------------------- |
| Entra ID ユーザー一覧                    | `User.Read.All`                                                  |
| Entra ID グループ一覧 / Teams チーム一覧 | `Group.Read.All`                                                 |
| Entra ID デバイス一覧                    | `Device.Read.All`                                                |
| Intune デバイス一覧                      | `DeviceManagementManagedDevices.Read.All`                        |
| Microsoft 365 ライセンス一覧             | `LicenseAssignment.Read.All`（`Organization.Read.All` でも可） |
| SharePoint リスト / ライブラリ           | `Sites.Read.All`                                                 |
| Outlook 予定表                           | `Calendars.Read`                                                 |
| OneDrive（組織）                         | `Files.Read.All`                                                 |
| Teams タスク & Planner                   | `Tasks.Read.All`, `Group.Read.All`                             |

## EveryDB 側の入力項目

| 項目                                      | 入力する値                                             | 備考                                                                  |
| :---------------------------------------- | :----------------------------------------------------- | :-------------------------------------------------------------------- |
| 保存済みトークンプロファイル              | 手順 3・4 の認証情報を含む Graph プロファイル          | 接続側では**選択…** で参照します。シークレットの有効期限に注意 |
| サイトURL（SharePoint のみ）              | `https://<テナント>.sharepoint.com/sites/<サイト名>` | サイト/チームから選択も可能                                           |
| 対象ユーザー（予定表 / OneDrive（組織）） | UPN またはメールアドレス                               | 接続設定のテーブル一覧からは追加できません                            |
| 対象チーム(グループ)のID（Planner）       | Entra のグループ ID                                    | 同上                                                                  |

「Outlook 予定表 / OneDrive（組織） / Teams タスク & Planner」は対象を指定する必要があるため、
接続設定画面のテーブル一覧には出ません。データソース一覧の **＋追加** から個別に追加してください。

## よくあるエラーと対処

| 症状                                       | 原因                                           | 対処                                                   |
| :----------------------------------------- | :--------------------------------------------- | :----------------------------------------------------- |
| `401 invalid_client`                     | シークレットの**ID** を貼った / 期限切れ | 手順 4 の**値**を貼り直す                        |
| `403 Authorization_RequestDenied`        | アクセス許可が無い・同意していない             | 手順 5〜6 を実施                                       |
| `AADSTS700016`                           | クライアント ID がテナントに存在しない         | テナント ID とクライアント ID の対応を確認             |
| トークン発行が条件付きアクセスで拒否される | 組織のアクセス制御ポリシーに適合していない     | Entra 管理者へポリシーと対象アプリの設定確認を依頼する |
| SharePoint で 0 件                         | サイト URL の誤り /`Sites.Read.All` 不足     | サイト URL を「サイト/チームから選択」で入れ直す       |
