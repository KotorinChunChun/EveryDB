# Notion データベースの接続手順

対象の EveryDB 種別: **Notion データベース**

## 概要

Notion の「インテグレーション（内部連携）」を作成し、そのトークンで API からデータベースの
中身を取り込みます。**インテグレーションに接続（共有）したデータベースだけ**が対象になります。
ワークスペース全体が自動的に見えるわけではない点に注意してください。

## 事前に必要なもの

- Notion のワークスペースと、そこでインテグレーションを作成できる権限
- 取り込みたいデータベース（テーブルビューを持つページ）

## 手順

1. [My integrations](https://www.notion.so/my-integrations) を開きます。
2. **新しいインテグレーション**（New integration）を押し、名前（例: `EveryDB`）と関連付けるワークスペースを選んで作成します。
3. 種類は **内部**（Internal）のままで構いません。作成後の画面に出る **内部インテグレーションシークレット**
   （`ntn_` で始まる文字列）をコピーします。これが EveryDB の「インテグレーショントークン」です。
4. **取り込みたいデータベースを Notion で開き**、右上の **…** →「**接続**」（Connections / コネクトの追加）から
   手順 2 で作ったインテグレーションを選びます。**この操作をしないと一覧に出ません。**
5. EveryDB で **＋接続先** → **Notion データベース**を選び、保存済みトークンを選択します。
6. 「自動設定」で **URLから自動入力**または、その右隣の**データベース一覧から選択…**を使って対象を指定し、
   **保存してリロード**を押します。

## EveryDB での安全な登録方法

秘密のトークンは接続設定に直接保存しません。

1. **設定** → **🔑 保存済みトークンの管理…** を開き、種別 **Notion** のプロファイルを新規作成します。
2. 任意のラベル（例: `個人用 Notion`）と、手順 3 でコピーしたトークンを入力して保存します。
3. Notion 接続の追加・編集画面でトークン欄の **選択…** を押し、保存したプロファイルを選びます。
## EveryDB 側の入力項目

| 項目 | 入力する値 | 備考 |
| :--- | :--- | :--- |
| 保存済みトークンプロファイル | 手順 3 の `ntn_...` を含む Notion プロファイル | 接続側では **選択…** で参照します |
| データベースID | URL 内の 32 桁の ID | テーブル一覧から選べば自動で入ります |
| データベース名 | Notion APIから取得した最新名 | 読み取り専用です。最後に取得できた名前を保存します |
| 表示名 | Notion APIから取得した最新名 | 読み取り専用で、データベース名と常に同じ値になります |

データベース ID は、Notion でデータベースをブラウザ表示したときの URL
`https://www.notion.so/<ワークスペース>/<32桁のID>?v=...` の 32 桁部分です。
一覧選択、URL・ID入力、既存設定の編集、通常の再読み込み時にはIDを使って名前を再取得します。
取得に成功すると、以前の表示名が手動設定値であっても、データベース名と表示名の両方をNotion側の最新名へ更新します。
アプリ側からこの2つの名前は変更できません。

通信や権限確認に失敗した場合は、画面に失敗理由を表示します。保存済みのデータベースID、最後に正常取得した
データベース名、表示名は空欄やID短縮名へ戻さず、そのまま維持します。新規追加時は現在のIDに対応する名前を
正常取得できるまで保存できません。

## よくあるエラーと対処

| 症状 | 原因 | 対処 |
| :--- | :--- | :--- |
| 一覧が 0 件 | データベースをインテグレーションに接続していない | 手順 4 を実施し **⟳ 更新** |
| `Notion API エラー 401` | トークンが誤っている・失効した | My integrations でシークレットを再取得 |
| `Notion API エラー 404` | 対象データベースの共有が外れた | 手順 4 をやり直す |
| 一部のデータベースだけ出ない | 個別に接続していない | データベースごとに手順 4 が必要 |
| 最新名の取得に失敗 | 通信断、トークン失効、共有解除、ID誤り | 表示された理由を確認します。最後の成功名と保存済み設定は維持されます |
