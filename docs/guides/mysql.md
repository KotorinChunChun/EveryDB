# MySQL の接続手順

対象の EveryDB 種別: **MySQL**

## 概要

MySQL / MariaDB サーバーへ直接接続し、指定したテーブルの内容を取り込みます。
**読み取り専用のユーザー**を用意することを強く推奨します。

## 事前に必要なもの

- サーバーのホスト名 / ポート / データベース名
- 接続ユーザーとパスワード（対象テーブルへの `SELECT` 権限）
- ファイアウォールで EveryDB を動かす PC からの接続が許可されていること

## 手順

1. サーバー管理者に、読み取り専用ユーザーの作成を依頼します（例）。

```sql
CREATE USER 'everydb_ro'@'%' IDENTIFIED BY '（強いパスワード）';
GRANT SELECT ON app.* TO 'everydb_ro'@'%';
FLUSH PRIVILEGES;
```

2. リモート接続の場合は `bind-address` の設定と、接続元ホストの許可（`'user'@'ホスト'`）を確認します。
3. **設定** → **🔑 保存済みトークンの管理…** で種別 **MySQL** のプロファイルを作成し、読み取り専用ユーザー名・パスワードを保存します。
4. MySQL 接続の追加・編集画面で認証情報欄の **選択…** を押し、保存したプロファイルを選んでから、**保存してリロード**を押します。
   インターネット越しに接続する場合は **TLS で接続する** を必ず ON にしてください。
5. 同じサーバーの別テーブルは、データソース一覧の **＋追加** から同じ保存済みトークンプロファイルを選んで追加します
   （MySQL はテーブル一覧の自動取得に未対応です）。

## EveryDB 側の入力項目

| 項目 | 入力する値 | 備考 |
| :--- | :--- | :--- |
| ホスト | `localhost` 等 | |
| ポート | 既定 `3306` | 空欄可 |
| データベース名 | 接続先 DB 名 | |
| テーブル名 | 取り込むテーブル | |
| 保存済みトークンプロファイル | 読み取り専用ユーザー名・パスワードを含む MySQL プロファイル | 接続側では **選択…** で参照します |
| TLS で接続する | リモート接続時は ON | |
| 自己署名証明書を許可 | 社内サーバーで自己署名を使う場合のみ ON | |

## よくあるエラーと対処

| 症状 | 原因 | 対処 |
| :--- | :--- | :--- |
| `Can't connect to MySQL server` | ホスト/ポート誤り、`bind-address` | 手順 2 を確認 |
| `Access denied for user` | 認証情報・接続元ホストの誤り | `'user'@'ホスト'` の指定を確認 |
| `Unknown database` | データベース名の誤り | 名前を確認（大文字小文字に注意） |
| TLS 関連のエラー | サーバーが TLS 未対応 / 自己署名 | 社内なら「自己署名証明書を許可」を検討 |
