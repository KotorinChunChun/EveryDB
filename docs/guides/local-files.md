# ローカルファイル系の接続手順

対象の EveryDB 種別: **CSV ファイル / Excel（テーブル・シート・シート名一覧）/
SQLite データベース / Access (accdb, mdb) / フォルダのファイル一覧 /
IME 辞書（Microsoft IME・Google 日本語入力）/ ブラウザ（閲覧履歴・ブックマーク・ダウンロード履歴）**

## 概要

PC 上（またはネットワーク共有上）のファイルを直接読み取ります。API キーや認証は不要で、
**EveryDB を実行しているユーザーがそのファイルを開ける**ことだけが条件です。

## 手順

1. データソース一覧の **＋追加** を押します。
2. **種別**を選び、**参照…** からファイル（またはフォルダ）を指定します。
   エクスプローラーの「パスのコピー」で付く前後のダブルクォートは自動で除去されます。
3. 種別ごとの追加項目を入力します（下表）。
4. SQLite / Access / Excel テーブルは、**テーブル一覧から複数追加…** を押すと
   ファイル内のテーブルを一覧から一括で追加できます。
5. **保存してリロード**を押すと取り込みが始まります。

同じファイル内の別テーブルを後から増減したいときは、データソース一覧で接続先（ファイル）を
右クリック →「編集」を開き、下部の**テーブル一覧**でチェックを付け外しして保存します。

## 種別ごとの入力項目

| 種別 | 主な入力項目 |
| :--- | :--- |
| CSV ファイル | パス / 文字コード / 改行コード / 区切り文字 / 先頭・末尾から読み飛ばす行数 / 先頭行はヘッダー |
| Excel: テーブル(ListObject) | パス / テーブル名（**xlsx・xlsm のみ**） |
| Excel: シート(セル範囲) | パス / シート名 / セル範囲（`A1:C10`）/ 先頭行はヘッダー |
| Excel: シート名一覧 | パス |
| SQLite データベース | パス / テーブル名 |
| Access (accdb / mdb) | パス / テーブル名 |
| フォルダのファイル一覧 | フォルダパス / サブフォルダも含める / 拡張子フィルタ |
| IME 辞書 | エクスポートしたテキスト辞書のパス |
| ブラウザ: 閲覧履歴 / ブックマーク / ダウンロード履歴 | ブラウザ種別（Chrome / Edge / Brave / Vivaldi / Firefox）/ プロファイル内のファイルパス |

> ダウンロード履歴は、Chrome/Edge/Brave/Vivaldi では**閲覧履歴と同じ `History` ファイル**の中に
> 保存されています（別ファイルではありません）。Firefox は `places.sqlite` を共有します。

### CSV の処理結果プレビュー

CSVファイルを指定すると、現在の解析設定を反映した先頭10行と末尾10行を自動表示します。
文字コード、改行コード、区切り文字、上下の読み飛ばし行数、ヘッダー有無を変更すると、
短い待機後にプレビューが更新されます。タイトル・注記・合計行が含まれるファイルでは、
この表示を見ながら読み飛ばし行数を決めてください。

- 文字コード: 自動判定 / UTF-8 / Shift_JIS
- 改行コード: 自動判定 / CRLF / LF / CR
- 区切り文字: カンマ / タブ / セミコロン / パイプ

プレビューと保存後の取込は同じ解析処理を使用します。

## よくあるエラーと対処

| 症状 | 原因 | 対処 |
| :--- | :--- | :--- |
| ファイルが見つからない | パスの誤り、ネットワークドライブ未接続 | **参照…** で選び直す |
| Excel テーブルが読めない | `.xls` 形式 | xlsx / xlsm で保存し直す |
| Access で ODBC エラー | Access ODBC ドライバ未導入 | Microsoft Access Database Engine を導入（**ビット数を EveryDB に合わせる**） |
| ブラウザ履歴/ダウンロード履歴が読めない | ブラウザが起動中でファイルがロックされている | ブラウザを終了して再読込 |
| 文字化け | 文字コードの判定がファイルと一致していない | プレビューで UTF-8 / Shift_JIS を明示指定して確認 |
| 1行・1列にまとまる | 改行コード・区切り文字が一致していない | プレビューを見ながら改行コードと区切り文字を変更 |
