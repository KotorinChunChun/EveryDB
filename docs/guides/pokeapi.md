# PokéAPI の接続手順

対象の EveryDB 種別: **PokéAPI**

## 概要

PokéAPIのGraphQLエンドポイントを利用して、ポケモンの図鑑番号、和名、タイプ、とくせい、種族値などのデータを一括で取得します。
認証（APIキーなど）は一切不要で、誰でも無料で利用できます。

## 事前に必要なもの

- インターネット接続（データを取得するため）
- 特に取得しておく必要のあるトークンやIDはありません。

## 手順

1. EveryDB のデータソース追加画面を開きます。
2. データソース種別から「PokéAPI」を選択します。
3. そのまま「追加」ボタンをクリックします。

## EveryDB 側の入力項目

| 項目 | 入力する値 | 備考 |
| :--- | :--- | :--- |
| なし | なし | 認証不要のため、入力する項目はありません。 |

## よくあるエラーと対処

| 症状 | 原因 | 対処 |
| :--- | :--- | :--- |
| ポケモンのデータが取得できない | ネットワークに接続されていない、またはPokeAPIのサーバーがダウンしている | インターネット接続を確認し、しばらく待ってから再度取得をお試しください。 |
