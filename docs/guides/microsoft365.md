# Microsoft 365（Graph API）接続方法の選択

対象の EveryDB 種別: **EntraID ユーザー / グループ / デバイス一覧、Intune デバイス一覧、
Microsoft 365 ライセンス一覧、Teams チーム一覧、SharePoint リスト / ドキュメントライブラリ、
Outlook 予定表、OneDrive、Teams タスク & Planner**

## 目的

Microsoft Graph の保存済みトークンを作成する前に、利用目的に合う認証方式を選びます。
認証方式によって、Entra ID に登録するアプリの種類、必要な権限、EveryDB の入力項目が異なります。

## 2つの認証方式

| 比較項目 | アプリケーション認証 | 委任 OAuth |
| :--- | :--- | :--- |
| EveryDB の表示 | アプリケーションの許可（クライアントシークレット） | 委任 OAuth（Microsoft にログインして認可） |
| 認証する主体 | Entra ID に登録したアプリ | Microsoft にログインしたユーザー |
| ブラウザでのログイン | 不要 | 初回認可時と再認可時に必要 |
| クライアントシークレット | 必要。期限管理が必要 | 不要 |
| Graph の許可の種類 | **アプリケーションの許可** | **委任されたアクセス許可** |
| 管理者の同意 | 原則必要 | 組織ポリシーや権限によって必要 |
| 取得できる範囲 | アプリへ付与したテナント範囲 | ログインユーザー本人がアクセスできる範囲 |
| EveryDB の対応範囲 | すべての Microsoft Graph データソース | 現在は SharePoint リスト / ライブラリと、そのサイト・Teams選択 |
| 向いている用途 | 定期実行、共有PC、テナント横断の管理データ | 個人の権限範囲、クライアントシークレットを保存したくない場合 |

## どちらを選ぶか

### アプリケーション認証を選ぶ場合

次のいずれかに当てはまる場合はこちらを選びます。

- Entra ID、Intune、ライセンス、予定表、OneDrive、Plannerを取り込みたい
- ユーザーがログインしていない状態でも定期リロードしたい
- 組織全体のデータを、管理者が許可した範囲で取得したい

[アプリケーション認証の設定手順を開く](microsoft365-app-only.md)

### 委任 OAuth を選ぶ場合

次の条件に合う場合はこちらを選びます。

- SharePoint リストまたはドキュメントライブラリを取り込みたい
- ログインしたユーザー本人が閲覧できるサイトだけを対象にしたい
- クライアントシークレットを作成・保存したくない

[委任 OAuth の設定手順を開く](microsoft365-delegated.md)

## EveryDB での選択方法

1. **設定** → **🔑 保存済みトークンの管理…** を開きます。
2. 種別で **Microsoft 365 (Graph)** を選びます。
3. **認証方式**で利用する方式を選びます。
4. **手順書**を押すと、現在選択している認証方式の個別ページが開きます。
5. 個別ページに従ってEntra IDとEveryDBを設定し、プロファイルを保存します。

認証方式を変更すると入力項目が切り替わります。方式の異なる既存プロファイルを流用せず、
用途ごとに別の保存済みトークンプロファイルを作成してください。

## 注意事項

- **アプリケーションの許可**と**委任されたアクセス許可**は別物です。同名の権限でも追加先を間違えると認証できません。
- 委任 OAuth のプロファイルをアプリケーション認証専用のデータソースへ割り当てると、権限不足になることがあります。
- クライアントシークレット、リフレッシュトークン、アクセストークンを手順書やスクリーンショットへ記録しないでください。
- 組織の条件付きアクセスや管理者同意ポリシーにより、追加の承認が必要な場合があります。
