# Microsoft 365 個人/組織 の Graph API 接続方法について

対象の EveryDB 種別: **Entra ID ユーザー / グループ / デバイス一覧、Intune デバイス一覧、
Microsoft 365 ライセンス一覧、Teams チーム一覧、SharePoint リスト / ドキュメントライブラリ、
Outlook 予定表、OneDrive（組織）、Teams タスク & Planner、OneDrive（個人）**

## 目的

Microsoftのデータを読み取るには、Microsoft Graph API を使用します。

会社・学校の Microsoft 365 テナントのデータの読み書きは **Microsoft Entra ID（組織）**、Outlook.com / Hotmail / Live  / OneDrive などの個人向けデータへのアクセス は **Microsoft アカウント（個人）**を使用します。

## アカウントとトークン種別

| 利用対象                   | EveryDB のトークン種別       | 使える認証方式          | 参考手順                                                              |
| :------------------------- | :--------------------------- | :---------------------- | --------------------------------------------------------------------- |
| 会社・学校の Microsoft 365 | Microsoft Entra ID（組織）   | アプリケーション認証    | [アプリケーション認証の設定手順](microsoft365-entra-app.md)            |
| 会社・学校の Microsoft 365 | Microsoft Entra ID（組織）   | ユーザー委任認証(OAuth) | [組織のユーザー委任認証 OAuth の設定手順](microsoft365-entra-user.md) |
| 個人 Microsoft アカウント  | Microsoft アカウント（個人） | ユーザー委任認証(OAuth) | [個人のユーザー委任認証 OAuth の接続手順](microsoft365-personal.md)    |

### 認証方式の違い

組織のデータにアクセスする場合は、アプリケーション認証が使用可能です。ユーザー委任認証との違いは以下のとおりです。

| 比較項目                   | アプリケーション認証                                         | ユーザー委任認証（OAuth）                                              |
| :------------------------- | :----------------------------------------------------------- | :--------------------------------------------------------------------- |
| 認証する主体               | Entra ID に登録したアプリ                                    | Microsoft にサインインしたユーザー                                     |
| 認証の手順                 | テナント ID、クライアント ID、クライアントシークレットを登録 | テナント ID、クライアント ID を登録し、Microsoft の認可画面で同意      |
| ログイン作業               | 不要                                                         | 初回認可時と再認可時にブラウザを立ち上げてサインイン後に連携を同意する |
| クライアントシークレット   | 必要。有効期限があり定期更新が必要                           | 不要                                                                   |
| 管理者の同意               | 必要                                                         | 場合によっては必要になることがある                                     |
| データにアクセスできる範囲 | アプリに許可されたテナント全体                               | サインインユーザーに許された範囲                                       |
| 向いている用途             | 無人PCによる定期実行、組織全体のデータ管理                   | 利用者本人のデータにアクセスする便利ツール                             |
