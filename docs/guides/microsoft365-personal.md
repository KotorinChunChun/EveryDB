# 個人のMicrosoft アカウントの接続手順

対象の EveryDB 種別: **OneDrive（個人）**

> この手順は Outlook.com / Hotmail / Live などの **個人 Microsoft アカウント**専用です。
> 会社・学校の Microsoft 365 は [Microsoft Graph 接続方法の選択](microsoft365.md) から
> 組織向けの手順を選んでください。

## 概要

EveryDB に登録済みのパブリッククライアントを使い、Authorization Code + PKCE で
個人 Microsoft アカウントへサインインします。利用者が Entra 管理センターでアプリを登録したり、
クライアント ID を入力したりする必要はありません。サインイン本人の OneDrive を
`/me/drive` から読み取り専用で取得します。

- EveryDB のトークン種別: **Microsoft アカウント（個人）**
- EveryDB のデータソース: **OneDrive（個人）**
- 必要な入力: 任意のプロファイル名のみ。認証情報は Microsoft のログイン画面で認可します。
- 使用する委任権限: `Files.Read`, `User.Read`, `offline_access`
- テナント ID、クライアント ID、クライアントシークレット、対象ユーザー UPN は入力しません。

## 1. EveryDB で認可する

1. **設定** → **🔑 保存済みトークンの管理…** を開きます。
2. 種別 **Microsoft アカウント（個人）** のプロファイルを新規作成します。
3. 任意の名前を入力し、**🔗 個人 Microsoft アカウントで認可…** を押します。
4. 取り込む OneDrive を所有する個人 Microsoft アカウントでサインインし、表示された許可へ同意します。
5. **✅ 認可済み**を確認して保存します。

リフレッシュトークンは Windows DPAPI で暗号化して保存されます。認可を取り消した場合やトークンが失効した場合は、この手順をもう一度実行してください。
リフレッシュトークンやアクセストークンを手順書、スクリーンショット、ログへ記録しないでください。

以前のバージョンで利用者自身のクライアント ID を入力して作成したプロファイルは、認証設定の更新後に**再認可が必要**と表示されます。同じプロファイルで認可し直して保存してください。接続の作り直しやデータベース移行は不要です。

## 2. OneDrive（個人）を追加する

1. 接続設定のデータソース一覧で **＋追加**を押し、**OneDrive（個人）**を選びます。
2. 認証情報の **選択…**から、手順1で保存した **Microsoft アカウント（個人）**プロファイルを選びます。
3. 保存してリロードし、サインイン本人のファイルが表示されることを確認します。

組織用の **Microsoft Entra ID（組織）**プロファイルは選択できません。逆に、個人用プロファイルを
**OneDrive（組織）**や他の組織向け Graph データソースへ使用することもできません。

## よくあるエラーと対処

| 症状                               | 原因                                                                      | 対処                                                                                           |
| :--------------------------------- | :------------------------------------------------------------------------ | :--------------------------------------------------------------------------------------------- |
| 個人アカウントでサインインできない | 会社・学校アカウントを選んでいる、またはEveryDB側のアプリ設定に問題がある | 個人 Microsoft アカウントでやり直し、解消しなければエラー内容を添えてEveryDBの管理者へ連絡する |
| OneDrive（個人）を選択できない     | 組織用プロファイルを選んでいる                                            | Microsoft アカウント（個人）プロファイルを作成・選択する                                       |
| 認可後の取得に失敗する             | 認可の取消・失効、またはOneDriveが未作成                                  | Microsoft の認可をやり直し、ブラウザ版OneDriveを一度開いてから再試行する                       |

## 動作確認チェックリスト

- Microsoft アカウント（個人）の認可・保存が成功する。
- OneDrive（個人）の初回取得と再リロードが成功する。
- アプリ再起動後も保存済みプロファイルから再リロードできる。
