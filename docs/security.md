# プライバシーとセキュリティ

## ローカル保存

EveryDB のキャッシュDBは `%APPDATA%\com.everydb.app\cache.db` に保存されます。ソース設定、検索履歴、プリセット、キャッシュ済みレコードを含むため、バックアップや共有の際は内容を確認してください。

## 秘密情報

認証トークン、クライアントシークレット、DBパスワードなどの秘密フィールドは、Windows DPAPI により現在のWindowsユーザーへ紐付けて保護します。ソース設定では保存済み認証情報への参照を使えます。

秘密値を表示する操作ではWindows Helloによる本人確認を利用します。Windows Helloが利用できない環境では、アプリは確認可能かどうかを検出して動作します。実際の利用環境での本人確認設定は、Windows側の設定を確認してください。

## 外部通信

データ取得時、EveryDB は選択したデータソースのサーバーへ必要な認証情報とリクエストを送信します。各サービスのアクセス許可、共有範囲、保持期間、利用規約は利用者自身で確認・管理してください。

Webページ取り込み、公開iCal、政府公開データ、PokéAPIなどは指定URLまたは公開サービスへアクセスします。取り込み対象に含まれる個人情報・機密情報の扱いは利用者の責任です。

## 開く操作

セルや接続先を開く操作は、HTTP/HTTPS、file、Notion、FTP、mail、Teams、Obsidianの対応スキームを既定アプリへ渡します。実行形式やショートカット形式はアプリから開かないようにしています。

## アプリ権限とCSP

Tauri capabilityはメインウィンドウだけに限定し、ユーザーがダイアログで選択した出力先への書込みと、確認済みの参照先を開く権限だけを付与しています。ファイルシステムの全域スコープや読取り・削除・名称変更の権限は付与しません。

Content Security Policy（CSP）は外部ネットワーク接続を許可せず、Tauri IPCだけを許可します。`npm run security:check` はこれらの権限・CSPが意図せず緩和されていないことを確認します。
