# トラブルシューティング

このページでは、EveryDB の利用中に起きやすい問題を、データを消さずに確認する順番で案内します。接続先ごとの権限や入力項目は[データソース一覧と接続手順](data-sources.md)も参照してください。

## 更新が失敗する、または件数が増えない

1. サイドバーで対象ソースの最終更新時刻・状態を確認します。
2. 接続先のURL、ファイルパス、テーブル名、シート名、認証情報が現在も有効か確認します。
3. ネットワーク接続、VPN、プロキシ、接続先サービスの権限・共有範囲を確認します。
4. ソースの編集画面から「保存してリロード」を実行します。

更新中に取得したデータはローカルキャッシュへ保存されます。更新が失敗しても、既存のキャッシュを消去する操作は行わず、まず設定と接続先を見直してください。

## 検索結果が表示されない

- サイドバーで検索対象のソースにチェックが入っているか確認します。
- ソースが初回取得済みであること、更新時にエラーになっていないことを確認します。
- 検索語を短くして試します。複数語を空白で区切ると、すべての語を含む結果を検索します。
- 列の表示設定やソースの非表示設定を見直します。

## 保存済み認証情報を選べない・削除できない

認証情報は「設定」→「保存済みトークンの管理」で作成・更新します。使用中の認証情報は、参照しているソースがある間は削除できません。不要な認証情報を削除したい場合は、先に該当ソースを別の認証情報へ変更するか削除してください。

秘密値はWindowsのDPAPIで保護して保存されます。別のWindowsユーザーへキャッシュDBをコピーしても、元のユーザーの秘密値は利用できません。秘密値を含む画面やDBファイルを問い合わせへ添付しないでください。

## Windows Hello の確認画面が出ない

Windows Hello は秘密値を表示する操作の確認に使用します。利用可否はWindows側の設定、PIN・生体認証の登録状況、利用中の端末に依存します。Windows Helloを利用できない場合の動作も含め、秘密情報の保護はDPAPIによりWindowsユーザーへ紐付いています。

Windows Helloの設定方法はWindowsの公式設定画面を確認してください。EveryDBのトークンを手動で別の場所へ書き出して回避しないでください。

## Box の認可が完了しない

Box のユーザー認証では、ブラウザでの認可後にEveryDBへ戻る必要があります。

- クライアントIDとクライアントシークレットが正しいか確認します。
- Box側でユーザー認証（OAuth 2.0）を許可したアプリ設定か確認します。
- 認可中に別のアカウントで操作した場合や不要になった場合は、認可ダイアログの取消操作を使ってからやり直します。
- 認可後にリフレッシュトークンが返らない場合は、Boxアプリの認可方式と権限を確認します。

## 参照先を開けない

セルや接続先を開く操作では、HTTP/HTTPS、file、Notion、FTP、mail、Teams、Obsidianの対応スキームを既定アプリへ渡します。実行ファイルやショートカット形式は安全のため開きません。

開けない場合は、URL・パスの形式と、Windowsに対応アプリが関連付けられているかを確認してください。安全上ブロックされる形式を回避するために、拡張子を変更したり実行形式を許可したりしないでください。

## エクスポートしたCSVが文字化けする

出力形式に応じて文字コードを選びます。

- 他の多くのアプリ・サービスで使う場合: UTF-8
- Excelなどでの互換性が必要な場合: UTF-8（BOMあり）またはShift_JIS

Shift_JISで表現できない文字は置換されることがあります。元の文字を確実に保持したい場合はUTF-8を選んでください。

## 起動できない、または移行前にバックアップしたい

キャッシュDBは `%APPDATA%\com.everydb.app\cache.db` にあります。アンインストール、再インストール、手動調査の前に、EveryDBを終了してからこのファイルを安全な場所へコピーしてください。

このファイルにはソース設定、検索履歴、プリセット、キャッシュ済みレコードが含まれる可能性があります。共有先・バックアップ先のアクセス権限に注意してください。問題の切り分け目的であっても、バックアップを取らずに削除しないでください。

## 問い合わせ時に共有すると役立つ情報

次の情報を、秘密値を除いて共有してください。

- EveryDBのバージョン、Windowsのバージョン
- 使用しているデータソース種別
- 実行した操作と、表示されたエラーメッセージ
- 問題が起きた日時、再現するかどうか

トークン、パスワード、クライアントシークレット、キャッシュDBの内容、個人情報を含む検索結果は共有しないでください。バグや機能要望はREADME記載のGitHub IssuesまたはTwitterから連絡できます。
