# 第三者表示の出典

0.1.1は0.1.0と同じ固定依存を使用する。THIRD_PARTY_NOTICES.txtは公開済み0.1.0の同名asset（SHA-256: 263bb36358169a4a8f1bf0e5142d291ffb69d3e938d199dc53b9b9eb49c9a226）の本文を維持し、先頭の製品版番号だけを取り除いたもの。392件の表示を収録する。共通maintenanceに必要な.NETの表示は親の配布工程で別途同梱する。

依存版を変更した際は、固定したCargo.lockとpackage-lock.jsonに対応する全ライセンス本文を再生成・照合してから公開する。過去の表示をそのまま流用しない。
