# v0.0.3-req EveryDB 要求仕様書

## 実装済

> v0.0.3 で全項目を実装し、実機確認済み。実装内容の対応づけは [`v0.0.3-imp.md`](./v0.0.3-imp.md) を参照。

- 列見出しを左クリックしたら昇順または降順でソートできるようにして。この順序は再起動まで記憶する。クリックの度に昇順・降順・解除の３つの状態をトグルさせる。
- テーブル追加ボタンの位置をデータソース一覧の右上「管理」ボタンの左に変更
- データソースを絞り込みのボックスに何か入力されているとき、右端にバツボタンを置いて入力を消せるようにしてほしい。
- 全選択や全解除のボタンですが、絞り込み中に行ったとき、検索結果で可視化されているテーブルのみに対して変更を反映してほしい
- 接続設定画面で、テーブルの追加画面が独立しているが、接続設定画面の下部にリスト表示してほしい。
- Notionの接続設定画面で、データベース一覧が取得できていない。APIからアクセス可能なデータベース一覧を出して欲しい。また、データベースのアクセス許可を出すためのAPIの設定画面へすぐ飛べるボタンがほしい。設定後DB一覧を取得する必要があるため、更新ボタンもほしい。
- 接続設定において、APIキー入力欄の横に、APIキーを取得するサイトを開けるボタンを置いて
- 接続先種別ごとに必要な手順書を開くボタンを置いて（docの中にmdで作成するのでテンプレ作って）
- Microsoft365の接続設定画面でも、他のDBと同じように使用可能なテーブル（仕様として組み込んだ各種）の一覧を表示してワンクリックで追加できるようにして。
