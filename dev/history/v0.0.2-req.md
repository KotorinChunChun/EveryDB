# v0.0.2-req

### 実装済

- データソース設定や、テーブル設定の画面の上半分を折り畳みして、下のリストがたくさん一度に見えるようにする機能が欲しい。
- 起動のショートカットキー Ctrl+Alt+Dを設定画面で変えたい。
- なぜか Ctrl+Shift+マイナスで拡大になるがしなくていい。なぜかCtrl+プラスで拡大できないので拡大したい。
- 値を右クリックした時のメニューに、このデータソースのテーブルを非表示 を追加。そしたらチェックが外れるようにする。
- 値を右クリックした時のメニューに、「テーブルを開く」（このデータソースのテーブル）と「このページを開く」（セルの値がURLの場合のみ押せて他はグレーアウト）を追加して。
- テーブルの削除ボタン、メニューやデータソース管理画面のものは、削除前に確認メッセージを表示して。
- 左上の見出し文字列 データソース一覧 (検索範囲) を データソース(接続先 > テーブル) に改名して。
- データソース一覧の接続先名をクリックしてドラッグしても並べ替え移動が行えないので、展開機能は残したまま、ドラッグ時に移動できるようにして。親のシングルクリックをチェック切り替えにして。接続先移動時は、移動元も移動先も接続先単位での囲いをして。また、移動先となる境界線部分に太線で「ここに入る」と分かるようなデザインを示して。展開の切り替えは左端の▼をクリックしたときか、ダブルクリックをしたときにして。
- テーブル編集画面の列の並び順変更の実装も同じデザインにして。
- 検索結果の表の見出しの並び順変更のドラッグの実装も同じデザインにして。
- ドラッグしても列の入れ替わりが起こらないバグを直して。列の入れ替えにあたっては、この列を保有している全てのデータソースの列を入れ替えて。また、列の設定を開いてみても「対応するデータソースが見つかりませんでした」となる問題も起きており、表示名からデータソース名を検知出来ていないバグがあるので直して。キャッシュしたデータを使ってもっと高速に列名と実フィールドの照合を行って。

- データソース管理の画面を廃止して、データソース一覧のペインで全てのことが出来るようにして。
  データソース一覧のペインの右上に「管理」というトグルを設置して、押したら横幅を大幅に拡大。管理トグルがONのとき更新間隔の入力欄や削除ボタンを表示して。その他の情報も全部出して（更新ボタンや最終更新日時など）。「接続先」にもボタンを置いて。子のテーブルの全件合計も出して。

- データソース画面の接続先にあるテーブル数の表示は削除して。
