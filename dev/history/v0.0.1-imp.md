## 1. 概要

v0.0.1 の初回コミット（全 15 データソース + M7〜M12）に続き、req / req2 で挙がった
**UI/UX 拡張・コピー機能・検索プリセット・データソース 14 種追加・二階層アーキテクチャ整備**を
実装した。これにより対応データソースは **全 29 種別**となった。

技術スタックは既存踏襲（Rust + Tauri v2 バックエンド / TypeScript + Vite フロントエンド、
キャッシュは SQLite + FTS5 trigram）。フロントはフレームワーク非依存の素の TypeScript。

## 2. 要件別・実装対応

### 2-1. UI / UX（REQ-UI-01 / REQ-UI-02）

| 要件 | 実装 |
| :--- | :--- |
| **REQ-UI-01** ズーム（Ctrl +/-/0） | `set_zoom`/`get_zoom` コマンド。`window.set_zoom()` を適用し `app_meta` に永続化、起動時に復元。設定ダイアログにも +/−/リセットボタンを設置。 |
| **REQ-UI-02** テーマ（Light/Dark/Night） | CSS 変数 `:root[data-theme="…"]` の 3 定義。`set_theme`/`get_theme` で永続化・復元。設定ダイアログの `<select>` から即時切替。 |

### 2-2. コピー機能（REQ-CP-01 / REQ-CP-02）

| 要件 | 実装 |
| :--- | :--- |
| **REQ-CP-01** マルチフォーマットコピー | グリッドセルの右クリックメニューに「値 / TSV / 見出し付き TSV / JSON」の 4 形式。見出し付き TSV は値が空の列を自動除外。 |
| **REQ-CP-02** Ctrl+C は値コピー維持 | キーボード `Ctrl+C` の既定動作は選択中セル 1 個の値コピーのまま（`copySelected`）。多形式は右クリック経由のみ。 |

### 2-3. 検索プリセット（REQ-BM-01）

- `search_presets` テーブル + `save_search_preset` / `list_search_presets` / `delete_search_preset`。
- 保存対象: 検索クエリ文字列 + 選択中データソース ID 群。ツールバーの「☆保存 / ★一覧」から
  保存・呼び出し。呼び出すとクエリとデータソース選択状態を復元。
- 検索履歴（お気に入りとは別）も `search_history` に保存し、検索ボックスフォーカス時に表示。

### 2-4. データソース 14 種追加（req §2-4 / req2 6〜15 行目）

全て `Connector` trait 実装 + `TYPE_DEFS`（フロント動的フォーム定義）+ `secret::secret_keys`
（DPAPI 保護対象）+ `build_connector` ファクトリへの登録、の 4 点セットで追加。

| Group | 種別 | 実装方針 | 検証 |
| :--- | :--- | :--- | :--- |
| A | Entra デバイス / Intune デバイス / M365 ライセンス / Outlook 予定表 / OneDrive / Teams Planner | 既存 `GraphAuth`+`GraphClient`（クライアントクレデンシャル）を再利用 | ✅（Intune のみ 401＝テナントに Intune ライセンス無し。実装は正） |
| B | Google スプレッドシート | サービスアカウント JSON 鍵をファイルから読込み、`jsonwebtoken` で RS256 JWT を自前署名 → JWT-bearer でトークン取得 | ✅ |
| C | Google カレンダー / iCal | 認証不要。公開 iCal URL を取得し RFC5545 をパース（行アンフォールド・エスケープ処理は自前、Rust の raw 文字列で実装） | ✅ |
| D | Airtable | Personal Access Token で REST API。`offset` でページング | ✅ |
| E | Box | Client Credentials Grant（`box_subject_type=enterprise`）+ フォルダ再帰走査 | 実装のみ（ユーザー指示で未検証） |
| F | PostgreSQL / MySQL | ホスト直接接続。PG は `row_to_json(t)::text` 相当、MySQL は `mysql::Value` で型非依存に JSON 化 | 実装のみ（同上） |
| — | ブラウザ 閲覧履歴 / ブックマーク | Chromium 系（`urls`/JSON ツリー）・Firefox（`moz_places`/`moz_bookmarks`）。ブラウザがロックするため **一時ファイルへコピーしてから読む** | ✅ |

- Google/Airtable/Box/PG/MySQL のポート等、フロントが文字列で送る数値は `FlexPort`
  （untagged enum）で string/number 両対応。
- 新規シークレット（airtable=token / postgres・mysql=password / box=client_secret）を
  `secret_keys()` に追加し DPAPI 暗号化対象に。

### 2-5. テーブル表示・レイアウト（REQ-UI-03）

| 要件 | 実装 |

### 2-6. 列ヘッダーのコンテキストメニュー（REQ-UI-04）

## 3. セッション中に追加実装した項目（req2 の口頭延長）

req2 提出後のヒアリングで追加され、本バージョンに含めた項目。

### 3-1. 接続先 / テーブル 二階層アーキテクチャ（用語 §0 統一）

- **用語統一**: ツリー親＝「接続先」、子＝「テーブル」、総称＝「データソース」、全件＝
  「データソース全体 / リスト」。UI 文言・コメント・`docs/requirements.md` を統一
  （内部の変数名・型名はリファクタリスク回避のため対象外）。
- **接続先の右クリックメニュー**: 編集 / 再読込（配下全テーブル）/ 接続先を開く /
  削除（配下全テーブル・確認あり）。
- **接続設定ダイアログ**: 複数テーブルが共有する接続情報（パス・認証・ホスト等）を一括編集し
  配下全テーブルへ反映。表示名の上書きを `parent_label:<key>` として `app_meta` に永続化。
  接続種別を閲覧用ラベルで表示。
- **テーブル追加/削除ピッカー**: 接続設定から候補テーブル一覧をチェックで一括追加削除
  （SQLite / Access / Excel ListObject / SharePoint リスト・ライブラリ / Notion DB 対応）。
- **テーブル編集から接続情報を除去**: 接続先にグルーピングされたテーブルの編集画面では
  共有接続フィールドを隠し、「所属: {接続先名}」を閲覧表示。保存時は元値を引き継ぐ。
- **PostgreSQL/MySQL/Box も接続先グルーピング対象**に（host+database / enterprise_id をキーに）。

### 3-2. テーブル単位の「開く」コマンド

接続先だけでなくテーブル固有の Web ページが作れる種別は、テーブル右クリックにも
「このテーブルを開く」を条件表示。

- Notion（database_id→URL）/ Entra 各種・M365 ライセンス（Entra 管理センター）/ Intune /
  Teams 管理センター / SharePoint リスト・ライブラリ（サイト URL + 名称、ベストエフォート）/
  Airtable / Google スプレッドシート / iCal。
- ファイル系（Excel/CSV/SQLite/Access/folder）・PG/MySQL/Box は非対応（接続先を開くのみ）。
- Outlook 予定表 / OneDrive / Planner は設定値に無い情報（ドメイン・プラン ID）が要るため見送り。

### 3-3. コネクタ修正・機能追加

- **Excel「テーブル」= ListObject に修正**: 旧実装は単なるシート全体読みだった。calamine の
  `load_tables`/`table_by_name` で真の ListObject を読むよう修正（`browse_excel_tables`
  追加）。旧 `sheet` キーは後方互換でシート全体読みにフォールバック。種別名を
  「Excel: セル範囲」→「Excel: シート(セル範囲)」に変更。
- **CSV の上下読み飛ばし行数**: `skip_rows_top` / `skip_rows_bottom` を追加。ヘッダー判定は
  読み飛ばした後の行に対して行う。
- **ファイル参照ダイアログの拡張子フィルタ**: 種別に応じた拡張子で絞り込み
  （Excel→xlsx/xlsm/xls、SQLite→sqlite 等、Access→accdb/mdb、CSV→csv、IME→txt、鍵→json）。
- **オフライン時のキャッシュフォールバック**: 編集画面のフィールド取得でライブ接続に失敗した
  場合、キャッシュ済みレコード（`records.fields_json`）から列名を復元し編集続行可能に
  （`db::cached_field_names`。`preview_source_fields_by_id` が `{names, from_cache}` を返す）。

### 3-4. グリッド・ダイアログの細部改善

- **「見出し」列の表示**: 死んでいた `Record.label` を「テーブル」列の隣に表示。
- **編集ダイアログの縦拡張・可変サイズ**: ビューポート高の 82% を既定に `resize: both`。
- **パス→表示名の順序入替 + 自動命名**: 新規追加時、パス入力/選択からファイル名を表示名へ
  自動反映（手動編集後は自動反映停止）。
- **再読込 / リセットボタンの再配置**: 役割一覧の下へ移動し、右隣に「リセット」新設。
  リセット/新規時は暫定的に 1 列目を見出しに自動選択（将来 AI 推定へ差し替え予定）。
- **編集画面に最終読み込み日時**: タイトル直下に `last_success_at` を小さく表示。

## 4. 開発中に発見・修正した重大バグ

要求外だが実用上必須のため修正・記録。

| バグ | 原因と修正 |
| :--- | :--- |
| **UI からのデータソース追加が全滅** | Tauri は Rust の `type_` 引数を JS 側で `type`（末尾 `_` 無し）として期待するが、フロント 5 箇所が `type_` のまま送っていた。`add_source`/`preview_source_fields` の呼び出しを全て `type` に修正。 |
| **ページ内ドラッグ&ドロップが全て無効** | Tauri v2 既定の OS レベル DnD フック（`dragDropEnabled: true`）が HTML5 ドラッグを握りつぶしていた。`tauri.conf.json` に `"dragDropEnabled": false` を追加。 |
| **列見出し右クリックの誤爆** | 列幅ハンドル（6px）が右隣列の左端と重なり、境界の右クリックが一つ左の列の設定を開いていた。ハンドルの `contextmenu` を `stopPropagation` で止めて解消。 |
| **`[hidden]` が効かないメニュー** | `.ctx-menu { display:flex }` が UA の `[hidden]{display:none}` をカスケード上書き。`[hidden] { display: none !important; }` をグローバル追加。 |
