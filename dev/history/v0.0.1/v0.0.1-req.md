# EveryDB 追加機能拡張・要件仕様書

## 1. 概要

本仕様書は、EveryDB のユーザー体験（UI/UX）、データ操作性、検索条件の再現性、および対応データソースのさらなる拡大を目的とした追加要求仕様を整理したものです。

---

## 2. 機能要件

### 2-1. UI / UX・アクセシビリティ強化

#### 【REQ-UI-01】ズーム倍率変更（拡大・縮小）

- **概要**: キーボードショートカットにより、アプリ全体のUIおよびフォントサイズを動的に拡大・縮小可能とする。
- **操作仕様**:
  - `Ctrl` + `+` (または `Ctrl` + `Shift` + `;`/`=`): アプリ表示の拡大
  - `Ctrl` + `-`: アプリ表示の縮小
  - `Ctrl` + `0`: ズーム倍率を標準（100%）にリセット
- **仕様詳細**: 設定されたズーム倍率はローカル設定に保持し、次回起動時にも維持する。

#### 【REQ-UI-02】テーマ切替機能（Dark / Light / Night）

- **概要**: ユーザーの作業環境や好みに応じてUIテーマを変更できる設定を追加する。
- **実装テーマ**:
  - **ライトモード (Light)**: 明るい標準UI
  - **ダークモード (Dark)**: VSCode等のエディタで一般的なダークテーマ
  - **ナイトモード (Night / High Contrast)**: 黒背景に視認性の高い配色を施した高コントラストダークテーマ
  - ストレートブルー、ライトグレー＆ネイビー、チャコール、ウォームダーク など。
- **仕様詳細**: 設定画面より即時切り替え可能とし、選択されたテーマを保持する。

---

### 2-2. データ操作・クリップボード機能の拡張

#### 【REQ-CP-01】マルチフォーマット・コピー機能

- **概要**: セル/レコードのコピー時に、用途に応じた複数のフォーマットを選択してコピーできるようにする。
- **コピーフォーマット**:
  1. **値コピー (Plain Value)**: 選択セル/レコードの純粋な値テキスト（従来通り）
  2. **TSVコピー**: 選択行の全列をタブ区切りでコピー
  3. **見出し付きTSVコピー**: ヘッダー（列名）付きでTSVコピー。ただし **値が空（Null/空文字）の列は自動で除外** して整形
  4. **JSONコピー**: レコードの項目をキー・バリュー形式の JSON 文字列としてコピー
- **UI仕様**: コピーボタンのドロップダウンメニューまたは右クリックコンテキストメニューから形式を選択可能とする。

#### 【REQ-CP-02】ショートカットキー動作の維持

- **仕様**: キーボードの `Ctrl` + `C` 実行時は、混乱を防ぐため引き続き **「値コピー (Plain Value)」** を既定動作として維持する。

### 2-3. 検索条件・ソース設定の再現（ブックマーク機能）

#### 【REQ-BM-01】検索プリセット・お気に入り機能

- **概要**: 頻繁に使用する検索条件やデータソースの組み合わせをプリセット（ブックマーク）として保存・即座に再現できるようにする。
- **保存対象**:
  - 検索クエリ文字列
  - 選択中のデータソース（ON / OFF 状態、ソロ選択状態）
  - （オプション）列のフィルター・ソート状態
- **UI仕様**: 検索バー付近にお気に入り登録/呼び出しボタンを設置し、ワンクリックで保存した検索状態を復元可能とする。

### 2-4. 新規データソース・コネクタの拡充

#### ① カレンダー・タスク管理系

- **Teams タスク & Planner**: Planner のタスク一覧（タスク名、期限、担当者、進行状況、Bucket）
- **Outlook 予定表**: Microsoft Graph 経由での個人/共有カレンダーの予定一覧（件名、日時、場所、参加者）
- **Google カレンダー / iCal**: Google Calendar API 経由または `.ics` (iCal) ファイルからの予定一覧

#### ② オンラインスプレッドシート系

- **Google Spreadsheet**:
  - 指定スプレッドシートの指定テーブル
  - シート全域（表構造の自動検出）
  - 指定セル範囲 (例: `A1:D50`)

#### ③ クラウドストレージ系

- **OneDrive / Box / Google ドライブ**: 各クラウドストレージ内のファイル・フォルダメタデータ一覧（ファイル名、パス、更新日時、サイズ、Web URL）

#### ④ データベース & ノーコードツール系

- **PostgreSQL コネクタ**: 指定 DB / スキーマのテーブルデータのキャッシュ・検索
- **MySQL コネクタ**: 指定 DB / スキーマのテーブルデータのキャッシュ・検索
- **Airtable コネクタ**: Airtable REST API 経由でのベース / テーブル項目のキャッシュ・検索

#### ⑤ ローカルブラウザデータ系

- **ブラウザのブックマーク & 閲覧履歴**:
  - 対象: Chrome, Edge, Firefox, Brave 等
  - 実装方式: ローカルに存在する SQLite DB ファイル (`Bookmarks`, `History`) から直接読み取り・キャッシュ化

#### ⑥ M365 & デバイス / ライセンス管理系（管理者・情シス向け）

- **Entra ID デバイス一覧**: Entra ID (Azure AD) に登録されたデバイス情報（デバイス名、OS、準拠状態等）
- **Intune デバイス一覧**: Microsoft Intune 管理下のデバイス詳細情報
  - *注記: Intuneはライセンスを保有していないため、実装のみでテストは不要。*
- **Microsoft 365 ライセンス一覧**: テナント内のライセンス情報（ライセンス表示名、ライセンス名、SKU ID、総ライセンス数、消費数、残数）

## 2-5. UIレイアウト・テーブル表示・設定画面等の追加要求

#### 【REQ-UI-03】テーブル表示・レイアウトの操作性向上
- **列見出しの横スクロール対応**: テーブルの列見出し（ヘッダー）がデータ本体と同期して横スクロールできるように修正する。
- **左右分割パネルの動的リサイズ**: 画面の左右分割境界（スプリッター）をドラッグで動かせるようにする。
- **列幅の変更（カラムリサイズ）**: 各列の幅をドラッグ等で変更可能とする。

#### 【REQ-UI-04】列ヘッダーのコンテキストメニューと対応関係設定
- **列名・可視状態の変更**: 列見出しを右クリックして、列名の変更や表示/非表示（可視状態）の切り替えを行えるようにする。
- **データソース対応関係の選択**: メニュー内にデータソース一覧を表示し、該当列がどのデータソースの項目に対応しているかを選んで紐付け・変更できるようにする。

#### 【REQ-SET-01】設定画面への機能統合とUI配置見直し
- **ソース管理画面の閉じるボタン**: ソース管理画面の右上に「閉じる」ボタンを配置する。
- **取得上限値の設定移動**: 上限値の設定を設定画面の中に移動する（既定値: `10,000` 件）。
- **即時リロードボタンの移動と状態可視化**:
  - 即時リロードボタンを設定画面の中に移動する。
  - リロード実行中はアプリが応答なし状態に見えるため、リロード処理中であることが一目でわかるようUI上で可視化（ローディング表示等）する。

#### 【REQ-DS-01】データソース編集画面における初期表示改善
- **フィールド一覧の初期取得**: データソースの編集画面を開いた際、フィールド一覧を最初から自動的に取得して表示する。
- **再読込ボタンの位置づけ**: 既存の「フィールド取得」ボタンは「再読込ボタン」として位置づける。

## 3. 実装ロードマップ案

本拡張要件は影響範囲と種別により、以下のステップで進めることを推奨します。

1. **フェーズ 1: UI/UX & テーブル操作・設定画面の強化**
   - ズーム機能 (`Ctrl+`/`Ctrl-`)
   - テーマ切り替え（Light / Dark / Night）
   - コピー機能拡張（TSV / 見出し付きTSV / JSON）
   - テーブル表示改善（列見出し横スクロール、列幅変更、左右スプリッター動的変更）
   - 列ヘッダー右クリックメニュー（列名/可視状態変更、データソース対応選択）
   - 設定画面改修（上限値設定移動/既定値1万、即時リロード移動/ローディング表示可視化、ソース管理右上閉じるボタン）
   - データソース編集画面の初期フィールド取得および再読込ボタン化
2. **フェーズ 2: 検索プリセット & ローカルデータソース**
   - ブックマーク / 検索プリセット保存・再現
   - ブラウザのブックマーク & 履歴コネクタ
3. **フェーズ 3: M365 / Google / クラウド連携**
   - Teams Planner / Outlook 予定表 / Google カレンダー
   - Google Spreadsheet / 各クラウドストレージファイル一覧
   - Entra ID デバイス / Intune（※実装のみ・テスト不要） / M365 ライセンス一覧
4. **フェーズ 4: 外部 DB コネクタ**
   - PostgreSQL / MySQL / Airtable コネクタ
