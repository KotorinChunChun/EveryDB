# v0.0.4-req EveryDB 要求仕様書

## 実装済

> v0.0.4 で全項目を実装。実装内容の対応づけは [`v0.0.4-imp.md`](./v0.0.4-imp.md) を参照。

- TSV出力 ボタンは 出力に変更して、ダイアログで複数の形式を選べるようにして。tsv、csv、jsonなど
- 検索結果の画面で右クリックしてメニューを出した後、他のセルをクリックしてもメニューが消えない。消えるようにして
- データソース追加において「保存してリロード」をおしたとき、画面がフリーズしてしまうため、読み込み中であることを明示してほしい
- ブラウザのダウンロード履歴をデータソースとして登録できるようにして
- 各データソースの対応ブラウザにVivaldiも追加して（Chromium系です）
- 法人番号検索の任意の県の全データをインポートしたい（手段は問わない。検証は「岐阜県」を使う）
  https://www.houjin-bangou.nta.go.jp/download/zenken/index.html
- 郵便番号データベースをインポートしたい https://www.post.japanpost.jp/service/search/zipcode/download/utf/zip/utf_ken_all.zip
- WEBサイトの情報をデータソースとして登録できるようにしたい。例えばgetクエリの検索結果 https://zenn.dev/search?q=vba

## 質問と回答（QA）

実装前に確認した論点と決定。日付: 2026-07-26
（決定の技術的な理由・実測ログは [`v0.0.4-imp.md`](./v0.0.4-imp.md) の §0 を参照）

| # | 質問 | 回答 | 関係する要求 |
| :--- | :--- | :--- | :--- |
| 1 | 「出力」ダイアログで対応する形式と文字コードはどこまでやるか | TSV / CSV / JSON の 3 形式 + 文字コード選択（UTF-8(BOM付き) / UTF-8 / Shift_JIS） | TSV出力 → 出力ダイアログ |
| 2 | 例に挙がった zenn.dev の検索結果は JS 描画で HTML に結果が無い（実測）。WEB サイト取込はどの方式にするか | 「HTML表(table)の自動取込」「CSS セレクタ指定」「JSON API 取込」の 3 モードを 1 種別で切り替える | WEBサイトの情報をデータソース化 |
| 3 | 法人番号・郵便番号の取り込み方式（自動ダウンロード / 手動ファイル指定） | アプリ内で自動ダウンロード。法人番号は都道府県をプルダウンで選ぶだけにする。サイト改修で壊れた場合の代替として、手動でダウンロードした zip/CSV を指定する経路も併設する | 法人番号 / 郵便番号のインポート |
| 4 | 実機検証をどこまでやるか（実データ取込はキャッシュ DB が数百 MB 増える） | 岐阜県の法人番号と郵便番号全件を実際に取り込み、検索まで通して確認する | 法人番号 / 郵便番号のインポート |
